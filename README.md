# TabFold

**简体中文** · [English](README.en.md)

**让三星平板的开合动作，与屏幕动画自然衔接。** 开盖时画面逐渐展开，合盖时随动作收起，中途停留或反向展开也能跟随。

个人兴趣项目，免费开源。与 Samsung、Google 或 Apple 无官方关联。

## 功能

- **开合跟随**：根据平板姿态估算开合程度，驱动桌面、锁屏及其他允许的应用界面上的动画。
- **平滑合盖**：识别轻微且连续的合拢趋势，中途重新展开也能跟随。
- **后台响应**：启用后通过常驻通知维持后台检测，无需保持设置页打开；亮屏时检测动作，熄屏停止，醒来后恢复。
- **中英切换**：应用内可选择简体中文、English 或跟随系统。
- **设备识别**：显示设备名称、系统、屏幕、传感器能力及键盘连接状态。
- **按习惯调整**：校准展开位置、调整动画强度，单独开关合盖动画。
- **展开容差**：默认 ±3°，可调为 ±1°–±8°。展开进入容差范围即恢复清晰，适应支架每次落位的轻微差异。
- **轻量模式**：使用透明明暗变化，减少渲染负担。
- **本地处理**：无联网权限、无广告、无自动上传；可随时暂停或撤回同意。

## 下载与使用

到 [Releases](https://github.com/6ZLeo/TabFold/releases) 下载签名 APK，并核对同时发布的 SHA-256。最低 Android 13（API 33）；无需 Root 或持续连接电脑。

打开 TabFold，按首页的四步引导操作；页面会显示当前进度和下一步按钮。

1. **阅读说明**：点击“阅读说明并继续”，了解本地画面处理和风险，选择动画范围后自愿确认。
2. **开启服务**：点击“去开启系统服务”，在“已安装的应用”中开启 TabFold 开合盖动画，再返回应用。
3. **连接并校准**：键盘底座水平放稳，屏幕保持横向，展开到平常使用位置，点击“记住当前展开位置”。
4. **启动动画**：点击“启动动画并回到桌面”，按提示允许通知，可在常驻通知中直接暂停。随后打开普通应用，缓慢合盖、开盖即可；可在偏好中收窄为仅桌面与锁屏。

右上角 **Language / 语言** 可切换简体中文、English 或跟随系统。桌面预览按时间播放，正常使用按姿态驱动。

### 显示“受限设置”时

从浏览器下载 APK 安装后，Android 可能要求额外确认。点击应用内“遇到‘受限设置，无法开启’？”进入帮助，再打开 **TabFold 应用信息 → 右上角 ⋮ → 允许限制性设置**（部分系统称“允许受限制的设置”或“允许受限设置”）。按系统提示确认后，再开启无障碍服务。

这是 Android 针对安装来源的权限保护；应用不能自行授予或绕过。菜单受 One UI 和设备管理策略影响，详见 [Android 官方帮助](https://support.google.com/android/answer/12623953?hl=zh-Hans)。

可在应用内关闭自动动画，或使用“撤回同意并停用”；也可到系统辅助功能设置中关闭 TabFold 服务。

## 兼容性

| 项目 | 使用条件 |
| --- | --- |
| 系统 | Android 13 / API 33 或更高版本 |
| 设备 | 三星平板，并具备可用的姿态传感器 |
| 键盘 | 官方 Book Cover 键盘；其他实体键盘可在设置中选择允许 |
| 放置 | 键盘底座水平、固定，屏幕横向；仅移动屏幕部分 |
| 场景 | 桌面和锁屏；Android 14 起可包括其他允许的应用。受保护应用、系统设置和授权页跳过 |

**设备名称识别不等于兼容性认证。** 请查看 [兼容性说明](docs/COMPATIBILITY.md) 和 [发行说明](https://github.com/6ZLeo/TabFold/releases)，了解具体型号的验证范围。

键盘底座必须水平且固定。平板姿态不能直接测出独立移动的键盘角度；整套设备倾斜、放在腿上或仅移动键盘时可能误判。低端设备、不同 One UI、DeX、多窗口、竖屏和安全策略可能限制功能。

缺少姿态融合数据时，可使用重力或加速度基础模式，但动态动作的误差和延迟可能更大。

## 隐私与使用风险

首次启用前请阅读 [风险与责任说明](DISCLAIMER.md) 和 [隐私说明](PRIVACY.md)。无障碍服务用于识别所选范围内的窗口、获取允许截取的画面并显示动画层。普通应用画面可能含消息、账号资料等敏感信息。截图仅短暂存在于内存中，不保存或上传。

画面变形使用触发时的内存截图，因此实时内容会在动画退出后恢复显示。受保护锁屏截图失败时使用透明明暗层，不等于完整的锁屏画面变形，也不绕过锁屏或截图保护。普通应用先经系统检查目标窗口是否允许截图；拒绝时跳过动画，轻量模式也遵守此检查。

合盖检测与动画渲染可能增加耗电和发热。单次动画最多 12 秒，切换窗口时丢弃旧画面，熄屏时退出。Android 在后台绑定服务，系统功耗管理、强行停止或权限撤回仍可能中断它；应用中可检查服务连接并暂停。出现闪烁、卡顿或异常发热时，请停用并反馈。

软件按现状提供，不保证所有设备均可正常运行。责任限制仅在适用法律允许范围内有效，法律禁止排除的责任及法定权利不受影响。

## 本地构建

需要 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。将 SDK 路径写入自己的 `local.properties`，不要提交它。

```sh
./gradlew testDebugUnitTest assembleDebug lintDebug
./gradlew assembleRelease
```

Windows 使用 `gradlew.bat`。发布构建需要使用自己的密钥签名。
