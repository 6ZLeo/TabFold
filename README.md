# TabFold

**面向三星平板的开合盖动画工具。** 开盖展开，合盖收起；只有设置页面，没有 Today、Health 等演示面板。无需安装原版 DuoFold。

这是个人兴趣驱动的免费开源实验项目，不是 Samsung、Google 或 Apple 官方产品。首次启用前请阅读 [风险与责任说明](DISCLAIMER.md) 和 [隐私说明](PRIVACY.md)。本项目不承诺绝对安全或“概不负责”条款在所有情况下都有效。

## 下载与使用

到 [Releases](https://github.com/6ZLeo/TabFold/releases) 下载签名 APK，并核对同时发布的 SHA-256。最低 Android 13（API 33）；无需 Root 或持续连接电脑。

1. 安装并打开 TabFold，查看设备、传感器和键盘检测结果。
2. 阅读风险说明，自愿确认后开启功能。
3. 在系统“辅助功能 / 无障碍 → 已安装的应用”里开启“TabFold 开合盖动画”。应用不能替你授予此权限。
4. 将连接的键盘底座水平放稳，翻开平板到舒适位置，点击“将当前位置设为完全展开”。
5. 回到系统桌面，缓慢合盖、开盖。可用“到桌面试播”检查显示能力；试播按时间播放，实际动作按姿态驱动。

从早期 `DuoFold 平板测试` 迁移时，请先在系统里关闭旧版的无障碍服务，再启用 TabFold，避免两个动画服务同时运行。独立版使用新的包名和自己的设置，不会读取或删除旧版数据。

## 能做什么

- 判断桌面/锁屏场景，在亮屏后显示随开合角度估算变化的短暂动画层。
- 识别轻微、连续的合拢趋势，平滑进入反向动画；中途重新展开也能跟随。
- 显示当前设备名称、系统、显示与传感器能力、键盘状态；未知型号使用系统报告名称。
- 优先使用不依赖磁场的姿态融合数据。缺少融合数据时可使用重力或加速度基础模式，并显示精度限制。
- 调整展开位置、动画强度，单独关闭合盖检测；低性能设备可选轻量明暗模式。
- 检测官方 Book Cover 键盘系列；用户可选择允许其他实体键盘。
- 本地处理、无联网权限、无广告、无自动上传；支持撤回同意并停用。

## 兼容性与重要边界

**面向多种三星平板，不代表已在全部型号上验证。** 名称表含多个型号，但名称识别不等于硬件适配认证。详见 [兼容性说明](docs/COMPATIBILITY.md)。

早期实现已在 Galaxy Tab S10 Ultra（SM-X920）与官方 EF-DX925 键盘上验证开合动画。独立版本的具体测试状态以发行说明为准；其余型号欢迎提交不含个人信息的兼容性报告。

键盘底座必须水平且固定。平板姿态不能直接测出独立移动的键盘角度；整套设备倾斜、放在腿上或仅移动键盘时可能误判。低端设备、不同 One UI、DeX、多窗口、竖屏和安全策略可能限制功能。

桌面动画使用一次内存截图，因此小组件等实时变化会在动画退出后恢复显示。受保护锁屏截图失败时使用透明明暗层，不等于完整的锁屏画面变形，也不绕过锁屏或截图保护。只对桌面和锁屏尝试触发，不为普通应用统一施加动画。

合盖检测会增加传感器活动；动画会使用 GPU。单次最多 12 秒，进入其他应用或熄屏时退出。不承诺特定精度、耗电、延迟或帧率。

## 本地构建

需要 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。将 SDK 路径写入自己的 `local.properties`，不要提交它。

```sh
./gradlew testDebugUnitTest assembleDebug lintDebug
./gradlew assembleRelease
```

Windows 使用 `gradlew.bat`。含非 ASCII 路径的部分 Windows 环境可能影响 Gradle 测试工作进程，可使用 `run-tests.ps1` 执行同一批已编译测试。CI 在标准路径运行原生 Gradle 测试。

Release 构建默认不带发布私钥。维护者在仓库外签名，APK 签名证书指纹和文件校验值随发行公布。请勿向仓库提交密钥、签名密码、调试日志、设备截图或个人路径。
