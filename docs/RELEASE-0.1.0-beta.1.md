# TabFold 0.1.0-beta.1

首个开源测试版，为三星平板提供桌面与锁屏上的开合动画。

## 本次内容

- 更早识别连续合拢趋势，平滑进入合盖动画；半开停留、反向展开继续跟随。
- 三星平板型号名称、系统、显示、姿态传感器与实体键盘识别；按能力提供限制提示。
- 姿态融合优先，重力/加速度基础模式作为后备；支持校准、强度、轻量模式及单独关闭合盖检测。
- 首次使用需自愿阅读风险说明并启用；支持暂停及撤回同意。
- 无联网权限、无广告、无自动上传，截图仅在内存中用于短暂动画。
- 完整中文风险与责任说明、隐私说明、MIT 授权和第三方署名；提供英文项目简介。

## 安装

下载 `TabFold-0.1.0-beta.1.apk`，按 `SHA256SUMS.txt` 核对文件。要求 Android 13 或更新的三星平板及合适的姿态传感器。键盘底座需平放、固定。

安装 TabFold 后，阅读使用说明、开启系统服务并校准展开位置，再启动动画。

首次使用不需要 Root 或持续连接电脑；请勿为了本应用更改锁屏安全规则、其他应用权限或温控设置。

## 测试范围

- 18 项本地 JUnit 逻辑测试通过，覆盖角度映射、合盖趋势、场景限制、设备判断与同意状态。
- Debug/Release 构建成功，Android Lint 无问题报告。
- Android 15 平板模拟器：独立版首页显示、非三星设备禁止启用、AGSL 着色器编译及合成图案渲染检查。调试图案入口仅属于 Debug 构建，发布 APK 不包含该入口。
- Galaxy Tab S10 Ultra（SM-X920）+ EF-DX925、Android 16：早期版本的开盖、合盖与灵敏度修正已获实机使用者确认。**新独立安装包尚未完成该设备的整体验收**，不能把旧版确认视为本次所有改动均已实测。
- GitHub 自动构建与测试状态可在仓库 Actions 页面查看。

## 已知限制

本版是预发行版本，不代表已适配或验证所有三星平板。设备名称识别不等于兼容性认证。未完整验证其他型号、基础姿态模式、第三方键盘、DeX、多显示器及不同锁屏安全策略。

角度来自平板姿态估算，无法直接测量独立移动的键盘铰链。屏幕横向、底座水平且静止时使用；拿起整套设备、在腿上使用或仅移动键盘可能误触发。

受保护锁屏无法截图时使用透明明暗层；不解锁设备或绕过截图保护。不同系统的唤醒和截图延迟可能影响开盖动画。合盖检测与 GPU 渲染可能增加耗电和发热。

软件按现状提供，责任限制仅在适用法律允许范围内有效。请阅读 [风险说明](../DISCLAIMER.md)、[隐私说明](../PRIVACY.md) 与 [兼容性说明](COMPATIBILITY.md)。
