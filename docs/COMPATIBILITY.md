# 兼容性说明

## 条件检测与实测是两回事

| 项目 | 要求或行为 |
| --- | --- |
| 系统 | Android 13 / API 33 起；更早系统不能安装本构建 |
| 设备 | 三星平板；排除 Galaxy Fold/Flip 手机，手机内置铰链不等于外接键盘铰链 |
| 姿态 | 优先 game rotation vector，其次 rotation vector，再其次 gravity / accelerometer |
| 基础模式 | 重力/加速度可提供粗略估算，动态动作可能更不稳定，不能承诺与融合模式一致 |
| 键盘 | 默认识别 Book Cover、EF-DX、EF-DT 等实体键盘；第三方键盘须用户主动放宽匹配 |
| 放置 | 底座水平、固定，屏幕横向；仅移动屏幕部分 |
| 画面 | 原系统桌面及锁屏；受保护画面按系统规则退化为透明明暗层 |
| 后台 | 无障碍服务由系统绑定；不承诺厂商电源管理不会中断服务 |

名称映射根据 Google 公布的 Android 设备目录整理，仅用于显示型号对应的商品名称；不读取序列号或 Android ID。数据来源：https://storage.googleapis.com/play_public/supported_devices.csv 。名称表包含历史设备，不代表这些设备的系统版本满足安装条件。

## 常见问题

- 没有动画：确认已自愿启用、系统服务开启、当前处于桌面、键盘已识别、屏幕横向，且底座水平。先尝试桌面试播，再检查校准。
- 起始动画不可见：开盖亮屏、传感器和截图均存在系统延迟；不能重现息屏期间未观测的所有运动。
- 画面生硬：重新校准；合盖版本使用当前展开姿态作为反向动画参考，采用更小的连续趋势门槛和平滑衔接。
- 角度误判：检查整套设备是否一起倾斜、附件是否固定；基础加速度模式下慢动作更可靠。
- 卡顿或发热：降低动画强度，使用轻量明暗模式，或关闭合盖检测与自动动画。不要为了本软件关闭设备安全或温控保护。
- 锁屏只有明暗变化：这是受保护画面的预期降级，不应通过 Root、关闭锁屏或绕过安全策略解决。
