# TabFold 隐私与本地数据处理

版本：1 · 2026-09-11

TabFold 的官方应用没有 INTERNET、存储、照片、联系人或账号读取权限，没有广告 SDK、分析 SDK、自动遥测或后台上传接口。开源不等于绝对安全，请结合 DISCLAIMER.md 阅读。

## 处理哪些信息

| 信息 | 用途 | 保存与传输 |
| --- | --- | --- |
| 制造商、型号、Android 版本、显示规格、传感器能力 | 显示设备与兼容性提示 | 本机读取，不自动上传 |
| 实体键盘名称与连接状态 | 判断键盘是否连接 | 本机使用，不读取键盘输入 |
| 姿态传感器事件、估算开合角 | 驱动动画及识别开合趋势 | 本机内存处理；默认不记录日志 |
| 窗口所属应用及窗口类名、屏幕亮灭与锁定状态 | 限定桌面/锁屏场景、清除过时画面 | 仅处理必要元信息，不读取控件树和文字 |
| 当前桌面或允许截取的锁屏画面 | 构造一次开合动画 | 短暂存在系统/GPU/应用内存，不写入图片、不保存到相册、不上传 |
| 校准角、强度、功能开关、同意版本 | 保存用户选择 | 仅本应用私有设置，关闭系统备份 |

传感器在经同意的应用设置界面用于校准；在合格的亮屏桌面/锁屏上用于开盖动画或可关闭的合盖检测。进入其他普通应用、熄屏或暂停相关功能时停止自动动画和相应检测。轻量模式不请求画面截图，使用透明明暗层。

受保护画面截图失败时不绕过系统保护，也不把上一场景的旧截图用于当前锁屏。动画退出后释放应用持有的图像引用；不承诺底层内存立即清零。

## 可选操作

- “复制兼容性报告”只在用户点击时将报告写入系统剪贴板，不自动发送。报告不包含序列号、账号、设备唯一标识或屏幕图片。
- “本机诊断日志”默认关闭。开启后可能向 Android 日志写入角度、事件和窗口所属应用等诊断信息。调试日志由系统管理，关闭开关只停止后续记录，不会清除其他应用或整个系统的日志。
- 点击 GitHub 链接将打开系统浏览器。浏览器与 GitHub 按其各自规则处理网络访问；这不代表应用本身有网络权限。
- 主动提交 Issue、日志、录屏或截图属于用户主动向 GitHub 分享，请先检查是否含私人信息。不要提交完整系统日志或凭证。

## 撤回与删除

关闭自动动画可以暂停功能；关闭合盖开关可以停止待机合盖检测。使用“撤回同意并停用”会关闭自动功能并请求解绑本应用的无障碍服务，同时保留自己的校准设置；重新启用须重新阅读说明。可以通过系统清除本应用数据或卸载，移除自身设置。其他软件、系统日志、剪贴板历史以及用户主动分享到 GitHub 的内容，遵循各自的删除机制。

应用不会替你关闭其他无障碍服务，不修改其他应用数据或用户文件。请核验下载来源、签名及 SHA-256；第三方修改构建的权限和行为可能不同。
